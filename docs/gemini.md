# Запуск с Gemini API на Windows

LM Studio, llama.cpp и локальная модель для этого режима не нужны. Python веб приложение и SQLite остаются на компьютере; текст документа и четыре промпта отправляются Google. Первоначальные результаты и исправления сохраняются только после OK.

## Получение доступа

1. Откройте https://aistudio.google.com/ и войдите в аккаунт Google.
2. Создайте Gemini API key: https://aistudio.google.com/apikey . Не присылайте его в чат и не добавляйте в GitHub.
3. В Google AI Studio проверьте доступность API в вашей стране, выберите текстовую модель с поддержкой структурированных ответов и проверьте бесплатную квоту для вашего проекта. Скопируйте её API-идентификатор. Например, имя формата `gemini-2.5-flash` — это идентификатор, а не гарантия доступности или бесплатного использования в конкретном аккаунте.
4. Если нужен только бесплатный режим, используйте проект без подключённого платного биллинга. Приложение не контролирует тариф Google. HTTP 429 останавливает обработку; автоматического перехода на другую модель, платный сервис или повторных запросов нет. Каждый фрагмент обрабатывается четырьмя промптами, поэтому расходует несколько запросов. Проверка метаданных модели при старте не выполняет генерацию.

Доступность и правила использования данных у бесплатных тарифов меняются. Перед обработкой реальных персональных данных проверьте условия сервиса. Для первого запуска используйте вымышленные сведения.

## Простой запуск

Остановите старый Python сервер через Ctrl+C. Скачайте обновлённый проект с GitHub и скопируйте в вашу папку исходники, промпты, каталог scripts и start-gemini.bat, сохранив существующие `.venv312` и `data`. Устанавливать новые зависимости не нужно.

Откройте `start-gemini.bat` двойным щелчком. Он:

- найдёт `.venv312`, а при её отсутствии — `.venv`;
- запросит ключ скрытым вводом и идентификатор модели;
- проверит доступ к модели без отправки документа;
- запустит приложение на порту 8000.

Откройте веб страницу приложения на вашем компьютере. На странице должна быть надпись **Gemini API: текст документа отправляется Google для распознавания**. Оставьте окно запуска открытым. Ключ находится только в окружении процесса и не сохраняется в файлах или SQLite. При следующем запуске его потребуется ввести снова, если вы отдельно не задали переменную окружения.

## Запуск через PowerShell

```powershell
cd "C:\Projects\1-main"
.\.venv312\Scripts\python.exe .\scripts\start_gemini.py
```

Или задайте переменные вручную:

```powershell
$env:LLM_PROVIDER="gemini"
$env:GEMINI_MODEL=Read-Host "Введите идентификатор модели Gemini"
$secureKey=Read-Host "Введите API-ключ Gemini" -AsSecureString
$env:GEMINI_API_KEY=[System.Net.NetworkCredential]::new("", $secureKey).Password
Remove-Variable secureKey
.\.venv312\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

`GEMINI_TIMEOUT` задаёт тайм-аут запроса (по умолчанию 180 секунд, от 1 до 3600). Чтобы вернуться к локальному серверу, задайте `LLM_PROVIDER=local` и используйте прежние `LM_STUDIO_*` переменные. Список моделей можно запросить без передачи ключа в URL:

```powershell
(Invoke-RestMethod "https://generativelanguage.googleapis.com/v1beta/models" -Headers @{"x-goog-api-key"=$env:GEMINI_API_KEY}).models |
  Where-Object { $_.supportedGenerationMethods -contains "generateContent" } |
  Select-Object name
```

Это список доступных API моделей, а не список моделей с бесплатной квотой.

## Проверено и ограничения

Gemini подключён через официальный REST `v1beta/models/{model}:generateContent`. Отдельные промпты используют `systemInstruction`; ответ ограничен `responseMimeType=application/json` и `responseSchema`. Программные проверки используют подставные ответы, включая квоты, ограничения сервиса, NULL, исправления оператора и запись провайдера в SQLite. Реальные запросы с вашим ключом и качество Gemini на ваших документах ещё не проверены. Запуск BAT проверен чтением сценария, не выполнен на Windows из облачной Linux-среды.
